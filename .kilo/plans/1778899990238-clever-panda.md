## 4. Đề xuất Bổ sung theo Nhóm Ưu tiên

### Ưu tiên 1 — Core Productivity (Nên làm ngay)

#### 4.1 Parameter Manager
- **Mô tả:** Bulk edit, copy, swap parameters giữa elements/schedules
- **Tương tự:** DiRootsOne ParaManager, pyRevit ParameterTools
- **Tính năng:**
  - Export/Import parameters ↔ Excel
  - Bulk edit instance/type parameters
  - Copy parameters giữa elements
  - Search/replace parameter values
  - Create new shared/project parameters
- **Effort:** Lớn (2-3 tuần)

#### 4.2 Element Renamer
- **Mô tả:** Batch rename families, types, views, sheets, rooms...
- **Tương tự:** DiRootsOne FamilyReviser, pyRevit Renamer
- **Tính năng:**
  - Rename theo rule (find/replace, add prefix/suffix)
  - Preview trước khi apply
  - Undo support
  - Export rename log
- **Effort:** Trung bình (1-2 tuần)

#### 4.3 Transfer Standards
- **Mô tả:** Copy project standards giữa Revit files
- **Tương tự:** Revit built-in nhưng limited, CTC tools
- **Tính năng:**
  - Transfer: View Templates, Families, Materials, Line Styles, Object Styles
  - Selective transfer (chọn cái cần transfer)
  - Batch transfer từ multiple source files
- **Effort:** Lớn (2-3 tuần)

#### 4.4 Sheet Manager
- **Mô tả:** Batch create, duplicate, manage sheets
- **Tương tự:** DiRootsOne SheetGen
- **Tính năng:**
  - Batch create sheets từ Excel template
  - Duplicate sheets với views
  - Manage revisions, issue dates
  - Sheet numbering/reordering
  - Export sheet list ↔ Excel
- **Effort:** Lớn (2-3 tuần)

### Ưu tiên 2 — Model Management (Nên làm trong Q tiếp theo)

#### 4.5 Copy Views Between Projects
- **Mô tả:** Copy views (với overrides, filters, templates) giữa projects
- **Tương tự:** pyRevit CopyViews, CTC tools
- **Tính năng:**
  - Copy views: plans, sections, elevations, 3D, schedules
  - Preserve VG overrides, filters, view templates
  - Batch copy nhiều views cùng lúc
- **Effort:** Trung bình (1-2 tuần)

#### 4.6 Linked Elements Manager
- **Mô tả:** Quản lý visibility, overrides của linked models
- **Tương tự:** pyRevit LinkManager
- **Tính năng:**
  - Tab-based linked model management
  - Bulk VG overrides cho links
  - Link reload/unload/audit
  - Linked element query
- **Effort:** Trung bình (1-2 tuần)

#### 4.7 Advanced Filter
- **Mô tả:** Filter và colorize elements theo rules
- **Tương tự:** DiRootsOne OneFilter
- **Tính năng:**
  - Rule-based filtering (parameter, category, value)
  - Color-code elements trong view
  - Export filter results
  - Save/load filter profiles
- **Effort:** Trung bình (1-2 tuần)

### Ưu tiên 3 — Nice-to-Have (Có thể làm sau)

#### 4.8 CAD to Revit Importer
- **Mô tả:** Import DWG → Revit elements (walls, doors, pipes...)
-- **Tương tự:** Các specialized import tools
- **Effort:** Lớn

#### 4.9 Tab MDI (Multi-Document Interface)
- **Mô tả:** Tab-based navigation giữa open Revit files
- **Tương tự:** Kiwi Codes Project Browser
- **Effort:** Nhỏ-Medium

#### 4.10 Deleted Backup Service
- **Mô tả:** Auto-backup elements/files trước khi xóa
- **Tương tự:** Custom solution
- **Effort:** Nhỏ

#### 4.11 MEP/Electrical Tools
- **Mô tả:** Specialized tools cho MEP và Electrical disciplines
- **Effort:** Lớn (niche market)

## 7. Kết luận

**CombineCAD hiện tại rất mạnh về DWG Export/Merge** nhưng thiếu các công cụ productivity hàng ngày mà đối thủ (DiRootsOne, pyRevit) đã có.

**Gap lớn nhất:**
1. ❌ Parameter Management (bulk edit, Excel sync)
2. ❌ Element Renamer (batch rename)
3. ❌ Sheet Manager (batch create/duplicate)
4. ❌ Transfer Standards (between projects)
5. ❌ Copy Views (between projects)

**Điểm mạnh để tận dụng:**
- ✅ DWG Export/Merge tốt nhất thị trường
- ✅ Multi-version Revit support (2020-2027)
- ✅ Dark theme WPF UI
- ✅ License system + Installer
- ✅ AutoCAD integration (AcCoreConsole)
