## Các cải thiện đề xuất

### 1. Commands.cs — Thêm backward-compat fields + Directory.CreateDirectory + Sleep

**Vấn đề:** `WriteStatus` chỉ ghi PascalCase (`Success`, `Message`, `OutputPath`, `LogPath`). Nếu Revit-side đổi sang đọc camelCase (hoặc ngược lại), status sẽ deserialize thành default values (`false`, `null`) → coi như failure.

**Vị trí:** `src.acad/Licorp_MergeSheets/Commands.cs` — hàm `WriteStatus` (line 286-345)

**Thay đổi:**
- Thêm `success`, `output`, `error`, `log`, `timestamp` (camelCase) alongside PascalCase fields
- Thêm `Directory.CreateDirectory(Path.GetDirectoryName(statusPath))` trước khi ghi file
- Thêm `Thread.Sleep(200)` sau flush để đảm bảo file fully flushed trước khi process exit

```csharp
var status = new
{
    // camelCase — primary schema
    success = success,
    output = config.OutputPath,
    error = success ? null : finalMessage,
    log = logPath,
    timestamp = DateTime.Now.ToString("yyyy-MM-dd HH:mm:ss"),

    // PascalCase — backward compat
    Success = success,
    Message = finalMessage,
    OutputPath = config.OutputPath,
    LogPath = logPath
};
```

### 2. DwgMergeService.cs — MergeStatusDto đọc cả camelCase và PascalCase

**Vấn đề:** `MergeStatusDto` chỉ có PascalCase properties. Nếu plugin viết camelCase, tất cả properties sẽ là default (`false`, `null`).

**Vị trí:** `src/Licorp_CombineCAD.Shared/services/DwgMergeService.cs` — `MergeStatusDto` (line 1064-1070)

**Thay đổi:**
```csharp
private class MergeStatusDto
{
    public bool success { get; set; }
    public string output { get; set; }
    public string error { get; set; }
    public string log { get; set; }
    public string timestamp { get; set; }

    public bool Success { get; set; }
    public string Message { get; set; }
    public string OutputPath { get; set; }
    public string LogPath { get; set; }

    public bool IsSuccess => success || Success;

    public string EffectiveOutput =>
        !string.IsNullOrWhiteSpace(output) ? output : OutputPath;

    public string EffectiveMessage =>
        !string.IsNullOrWhiteSpace(error) ? error : Message;

    public string EffectiveLog =>
        !string.IsNullOrWhiteSpace(log) ? log : LogPath;
}
```
